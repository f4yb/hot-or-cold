Hot or Cold Engine V2

Two devices, one room code. The tracker measures distance, the seeker hears it.

Use two devices

For internet play, host this page on an HTTPS website (for example, GitHub Pages), open it on both devices, then share the seeker's link or 4-character room code. Keep both devices connected to the internet.

Bluetooth headphones connect to the seeker's device for audio. Direct phone-to-phone Bluetooth data connection is not supported by this browser version.

Testing on one device?

Open this page in two tabs of the same browser, make one the tracker and one the seeker, and use the same room code. They talk through the browser itself, no internet needed.
